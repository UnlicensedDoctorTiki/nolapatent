## NOLAPATENT: from WordPress back to static HTML

[**Explore the website project →**](https://github.com/UnlicensedDoctorTiki/nolapatent)

I'm using Codex, OpenAI's agentic coding system, to redesign and maintain [NOLAPATENT](https://www.nolapatent.com), my personal intellectual property law website. The project replaces an aging WordPress installation with ordinary HTML, CSS, JavaScript, and images.

I direct the design, supply and review content, and work with Codex on implementation. A small Python build script coordinates the parts that are tedious to maintain by hand: page layouts, navigation, article archives, related posts, RSS, the sitemap, and structured data. The published website needs no WordPress application or content database.

The repository includes both the editable source and the finished `dist/` website. I push updates to GitHub from Codex, then deploy by pulling them onto my Linux server and copying the generated files into the web directory. The server serves the files; it doesn't need to build the site.
