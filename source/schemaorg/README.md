The snapshot is used by `scripts/check_structured_data.py` to check known types, properties, inherited property domains, and allowed value ranges. Keeping it here makes validation repeatable without a network request. It is development data and is not copied into `dist/` or loaded by site visitors.

See the [Schema.org developer documentation](https://schema.org/docs/developers.html) for vocabulary downloads and the [Schema.org terms](https://schema.org/docs/terms.html) for source licensing and attribution. If the snapshot is deliberately refreshed later, review vocabulary changes, rerun validation, and update its recorded checksum.
