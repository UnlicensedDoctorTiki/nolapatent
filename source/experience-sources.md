## First Louisiana Civil Code iOS app

Matt directly confirms that he released the first Louisiana Civil Code iOS app. Jeff Richardson’s firsthand [October 22, 2009 iPhone J.D. review](https://www.iphonejd.com/iphone_jd/2009/10/louisiana-civil-code-code-of-civil-procedure-and-code-of-evidence.html) identifies Matt as the developer, explains that no one else was selling Louisiana law for iPhone, and describes the app’s search and reference features.
